# Longa Maimbo — portfolio

Static site for GitHub Pages. No build step.

- `index.html`: the whole site (Work, About, Experience, Contact)
- `assets/style.css`, `assets/main.js`: styles and behaviour
- `assets/img`, `assets/video`: web-optimised media
- `about.html`, `projects.html`, `Contact.html`: redirect old links to the matching section

To edit text, change `index.html`. To change the accent colour, edit `--accent` at the top of `style.css`.
